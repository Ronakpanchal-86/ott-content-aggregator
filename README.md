
# OTT Content Aggregator API

## Overview
The OTT Content Aggregator API is a backend application built using Python and FastAPI.

It aims to provide a unified platform to search and discover movies and shows across different OTT platforms.

## Tech Stack
- Python
- FastAPI
- Pydantic
- PostgreSQL
- SQLAlchemy
- Redis

## Current Features
- FastAPI application setup
- Movie listing endpoint
- Genre-based movie filtering
- Interactive API documentation using Swagger UI

## Installation

1. Clone the repository:
   git clone https://github.com/Ronakpanchal-86/ott-content-aggregator.git

2. Install dependencies:
   pip install -r requirements.txt

3. Run the application:
   uvicorn main:app --reload

## API Documentation
Open the following URL after starting the server:
    
http://127.0.0.1:8000/docs
